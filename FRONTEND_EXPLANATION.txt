1. PROJECT OVERVIEW & TECH STACK
================================================================================

This is a luxury travel agency website called "NextGen Travel" with a premium
editorial design inspired by high-end travel publications (Evaneos, Comptoir,
TravelTank). The aesthetic is "Snappy Noir Nature" - dark backgrounds mixed with
clean white sections, using glassmorphism and smooth snap animations.

TECHNOLOGIES USED:
  - HTML5 (semantic markup, data attributes, datalists)
  - CSS3 (custom properties, grid, flexbox, backdrop-filter, keyframe animations)
  - JavaScript (ES6+, async/await, IntersectionObserver, requestAnimationFrame)
  - Bootstrap 5.3 (modals, grid, forms, utilities)
  - Leaflet.js (interactive world map)
  - Supabase JS Client (backend auth, database, API calls)
  - Google Fonts (Playfair Display, Montserrat, Archivo Black, Inter)
  - Unsplash (all destination images loaded via CDN URLs)

  --font-serif:   'Playfair Display'  (headings, luxury editorial feel)
  --font-sans:    'Montserrat'         (body text, clean & legible)
  --font-display: 'Archivo Black'      (display/headline text, bold impact)
  + 'Inter' used throughout the search widget and modern UI components

ANIMATION CURVE:
  --ease-snap: cubic-bezier(0.34, 1.56, 0.64, 1)
    This is an "overshoot bounce" curve - elements slightly overshoot their
    final position and bounce back, giving a snappy, playful feel.

  --transition-snappy: 0.6s var(--ease-snap)
    The standard transition duration used for scroll reveal animations.

A. SCROLL REVEAL ANIMATION (.reveal-snap / IntersectionObserver)
----------------------------------------------------------------
  CSS (style.css lines 41-50):
    .reveal-snap {
      opacity: 0;
      transform: translateY(30px);
      transition: 0.6s var(--ease-snap);   /* cubic-bezier(0.34, 1.56, 0.64, 1) */
    }
    .reveal-snap.visible {
      opacity: 1;
      transform: translateY(0);
    }

  JS (main.js lines 59-69):
    Uses IntersectionObserver with threshold: 0.1
    When element enters viewport, adds 'visible' class
    Applied to: section headers, about cards, review cards, partner bar,
                vibe filters, continent filters, map section

  Effect: Elements slide up from 30px below and fade in with a slight
          overshoot bounce (the ease-snap curve makes them briefly go past
          their final position then settle back)

10. AVAILABILITY CHECK SYSTEM
================================================================================

This is a UX feature that checks if a trip/room is available before
redirecting to checkout.

FLOW:
  1. User clicks "Explore" button
  2. Full-screen overlay appears with loading spinner
  3. API call: api.checkTripAvailability(from, to, date)
  4. 12-second timeout applied via Promise.race
  5. If available_spots > 0:
     - Green checkmark icon
     - "Sanctuary Available" text
     - Auto-redirect to checkout.html after 1.2s
  6. If not available:
     - Red X icon
     - "Fully Booked for [date]" text
     - Alternative dates shown as buttons
     - "Continue to Reserve Anyway" button
     - "Browse Other Destinations" button
  7. On API failure:
     - Treats as available, redirects after 0.8s (graceful degradation)

FALLBACK SIMULATION (when API unavailable):
  - Random 35% chance of "fully booked"
  - Generates 3 random future dates as alternatives

CSS ANIMATION:
  Overlay: position fixed, inset 0, backdrop-filter blur(6px)
  Spinner: @keyframes avail-spin { to { transform: rotate(360deg); } }
  Modal: centered white card, 460px max-width
